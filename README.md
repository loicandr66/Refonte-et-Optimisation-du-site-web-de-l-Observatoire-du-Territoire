# Refonte et Optimisation du site web de l'Observatoire du Territoire
Projet de fin d'étude License en Informatique et Multimédia. Un redesign du site web tout entier, le construire avec de nouveaux langages de programmation web et l'ajout de nouvelles fonctionnalités

## Fonctionnalités / Améliorations
_ Responsivité des pages
_ Design récent
_ Technologies modernes et facile à utiliser
_ Pages de maintenance des données

## Technologies utilisées
_ HTML - CSS - JavaScript
_ NodeJs - VueJs - Bootstrap
_ ExpressJs - PostgreSQL

## Installation
```bash
git clone
https://github.com/loicandr66/Refonte-et-Optimisation-du-site-web-de-l-Observatoire-du-Territoire.git
cd Refonte-et-Optimisation-du-site-web-de-l-Observatoire-du-Territoire
npm install
npm run dev
```
Les détails du projet sont dans le mémoire PDF dans le repository.
